## Instruções
O banco de dados se encontra na pasta DATABASE
Execute o sql no banco de dados

Em seguida, copie e renomeie o ".env.example" para ".env" preencheendo o acesso e host do banco de dados
Se atentando a variável "APP_URL" que é a url do site

## Rodar sevidor local
```
php -S localhost:8000 -t public/
```
